# PlyCast 3NX

Web-based playout control for [CasparCG](https://github.com/CasparCG/server) – by [CiegoLink](https://ciegolink.com).

## Download

**[⬇ Latest release](https://github.com/ciegolink/plycast3nx/releases/latest)** · Windows 11 · Beta 3.0.10 (expires 1 December 2026)

## Features

- Playlists, templates, groups and emergency list
- Fixstart, Pause, Goto and HTTP API functions
- SCTE-104 via DeckLink (VANC) and IP
- MXF conversion with loudness normalisation
- Logos & HTML CGs, web upload and SFTP
- Output monitoring (freeze, black, silence) with email alerts
- Now Playing & Alarms API
- 8 interface languages

## Editions

**Free is a full playout – not a demo.** It runs a complete 24/7 channel with no time limit, no activation and no restrictions on air. Commercial use is allowed: TV stations, streaming channels and creators can broadcast with Free.

**Pro** adds what larger stations and professional workflows need – more channels, ad insertion, reporting and a bigger team.

| | Free | Pro |
|---|---|---|
| Channels | 1 | Up to 4 |
| SCTE-104 | – | ✓ |
| As-Run export MariaDB / MySQL | – | ✓ |
| Logos / CGs | 1 / 1 | Unlimited |
| Users | 2 | Unlimited |
| Playlists, templates, emergency list | ✓ | ✓ |
| Plugins and APIs | ✓ | ✓ |
| MXF conversion with loudness | ✓ | ✓ |
| Output monitoring and email alerts | ✓ | ✓ |
| Commercial use | ✓ | ✓ |

Upgrade to Pro directly in PlyCast under **Settings → License**.

## Quick start

1. Install and double-click the tray icon.
2. Sign in with `admin` / `admin` and set a new password.
3. **Settings:** check media folder and CasparCG connection.
4. Re-index media, build a playlist, press **Play**.
