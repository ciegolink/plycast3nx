# PlyCast 3NX

Web-based playout control for [CasparCG](https://github.com/CasparCG/server) – by [CiegoLink](https://ciegolink.com).

## Download

**[⬇ Latest release](https://github.com/ciegolink/plycast3nx/releases/latest)** · Windows 11 · Beta 3.0.11 (no expiry date)

## Features

- Playlists, templates, groups and emergency list
- Fixstart, Pause, Goto and HTTP API functions
- SCTE-104 via DeckLink (VANC) and IP – from the form or as your own XML
- Media Convert: switchable modules that check every file first and only convert what doesn't match (playout format, loudness, MP4 or MXF, broadcast-safe levels, colour space)
- Frame-accurate In/Out editor with fast preview proxies
- Logos & HTML CGs, web upload and SFTP
- Output monitoring (freeze, black, silence) with email alerts
- Now Playing & Alarms API
- 8 interface languages

## Editions

## Quick start

1. Install and double-click the tray icon.
2. Sign in with `admin` / `admin` and set a new password.
3. **Settings:** check media folder and CasparCG connection. Optional: switch on the modules you want under **Settings → Media Convert** – by default PlyCast only indexes and never changes your files.
4. Re-index media, build a playlist, press **Play**.
